# G98 云手机平台 — 快速上手

> 4 台 Android 13 云手机 + 微信 + 摄像头串流
> 板子地址：`192.168.99.50`  ·  SSH 密码：`1234`

---

## 一、看状态

浏览器打开：

```
http://192.168.99.50:8099/
```

会看到 4 台云手机的实时状态、机型、ADB 地址、微信是否已装。
表格里的 **WebRTC** 链接可以直接点开摄像头画面。

---

## 二、看摄像头

| 方式 | 地址 |
|---|---|
| WebRTC（推荐） | `http://192.168.99.50:8889/cam0` |
| HLS | `http://192.168.99.50:8888/cam0/index.m3u8` |
| RTSP（VLC） | `rtsp://192.168.99.50:8554/cam0` |

### 把摄像头换成你的脸

```bash
# 1. 上传照片
scp face.jpg root@192.168.99.50:/root/

# 2. 登录板子
ssh root@192.168.99.50

# 3. 替换摄像头内容
/root/cam-source.sh 0 /root/face.jpg

# 4. 刷新浏览器，看到的就是这张照片
```

也支持视频（mp4/mkv/avi/mov/webm），会循环播放。

## 三、登录微信

### 方式 A：一条命令（推荐）

```bash
/root/wechat-login.sh 1 你的微信ID 你的密码
```

参数：实例号（1-4）、微信ID/邮箱、密码。
脚本会自动走完登录流程并截图到 `/root/wechat_m1.png`。

### 方式 B：手动操作

```bash
adb connect 172.17.0.2:5555
adb -s 172.17.0.2:5555 shell am start -n com.tencent.mm/.ui.LauncherUI
# 然后按截图逐步点击，或用 scrcpy 投屏操作
```

### 4 台设备分别是

| 实例 | 机型 | ADB |
|---|---|---|
| m1 | Google Pixel 7 | `172.17.0.2:5555` |
| m2 | Redmi 2201123C | `172.17.0.3:5556` |
| m3 | OnePlus LE2123 | `172.17.0.4:5557` |
| m4 | Samsung SM-S918B | `172.17.0.5:5558` |

全部为 `user/release-keys` 零售版指纹，序列号各不相同。

## 四、常用操作

```bash
# 截图
adb -s 172.17.0.2:5555 exec-out screencap -p > m1.png

# 点击（坐标见截图）
adb -s 172.17.0.2:5555 shell input tap 360 640

# 输入文字
adb -s 172.17.0.2:5555 shell input text "hello"

# 安装 APK
adb -s 172.17.0.2:5555 install -r app.apk

# 重启某台云手机
docker restart m1

# 重启摄像头串流
bash /root/cam-bringup.sh
```

## 五、故障处理

| 现象 | 处理 |
|---|---|
| 面板打不开 | `systemctl restart g98-dashboard` |
| 摄像头无画面 | `bash /root/cam-bringup.sh` |
| ADB 连不上 | `bash /root/adb-ports.sh` |
| 云手机黑屏 | `docker restart m1` |
| 全部异常 | 直接重启板子，所有服务会自动恢复 |

## 六、已知限制

**App 内相机不可用。** 微信、相机 App 等调用系统相机 API 时会失败。

原因：redroid 镜像的 mapper@2.1 实现与 gralloc 的 YUV handle 不兼容，
且不提供模块级 hook 供外部介入。需要替换系统库或更换镜像才能解决。

**替代方案**：用上面「二、看摄像头」的 WebRTC 串流做认证，
画面内容可以替换成任意人脸照片或视频。

## 七、文件位置

```
/root/cam-bringup.sh     启动摄像头串流
/root/cam-source.sh      替换摄像头内容
/root/wechat-login.sh    微信一键登录
/root/adb-ports.sh       恢复 ADB 端口
/root/dashboard.py       状态面板
/root/G98-运维手册.md    完整文档（65KB）
```

systemd 服务：`camstream` / `adb-ports` / `g98-dashboard`（全部 enabled）

### 窗口焦点问题

如果 ADB 点击没反应，先执行：

```bash
/root/g98-wake.sh 1      # 或 all
```

仍无效则 `docker restart m1`。
